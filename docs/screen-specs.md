# 하루결 화면 명세 v0.5

상태: 구현 전 기준. 토큰·컴포넌트는 [디자인 시스템](design-system.md), 동작 규칙은 [제품 설계](product-design.md), 저장·계산은 [기술 설계](technical-design.md)를 따른다.
크기 기준은 폭 360~440dp 세로 화면이다. 가로 화면은 M1에서 세로 고정이다.

## 0. 공통

- 화면 구성: 상단 바 → 본문(스크롤) → 하단 메뉴. 하단 메뉴는 4개 최상위 화면(습관·할 일·캘린더·설정)에서만 보인다.
- FAB(＋): 습관 화면 = 습관 추가, 할 일 화면 = 빠른 추가, 캘린더 = 선택 날짜에 추가. 설정에는 없다.
- 뒤로 가기: 시트·대화상자 → 닫기, 하위 화면 → 이전 화면, 최상위 화면 → 습관 화면, 습관 화면 → 앱 종료.
- 저장 오류는 화면을 유지하고 상단에 오류 배너를 보여준다. 입력 중인 내용은 지우지 않는다.
- 모든 목록의 빈 상태: 상태 그림 + 한 줄 문구 + 동작 버튼 하나.

## 1. 습관 (첫 화면)

**상단 바:** 제목 ‘하루결’(title), 오른쪽 아이콘 ① 순서 변경(편집 모드 토글) ② 더보기(보관한 습관).

**본문 위에서 아래 순서**

1. 오늘 요약 카드(surface, 오프셋 그림자)
   - 왼쪽 큰 숫자 `3/5`(display), 아래 ‘오늘 달성’(body-s). 대상이 0개면 ‘오늘은 쉬는 날이에요’.
   - 오른쪽 이번 주 스티커 띠: 월~일 7개 원(32dp). 날짜 숫자가 원 안에 있고, 그날 대상 습관을 모두 달성하면 초록 채움 + 체크, 일부면 진행 링, 기록 없음은 점선, 미래는 숫자만. 오늘은 3dp 윤곽선.
   - 카드 아래 한 줄: ‘이번 주 스티커 12개’. 카드 전체를 탭하면 스티커 모음(6절)으로 이동한다.
2. ‘오늘 할 습관’ 구역: 오늘 대상이고 아직 달성하지 않은 습관 카드(DAILY·WEEKDAYS). sortOrder 순.
3. ‘이번 주 목표’ 구역: 주 N일 습관 중 이번 주 목표를 아직 못 채운 것. 카드에 ‘이번 주 2/3일’을 표시하고 오늘 기록 버튼은 그대로 있다.
4. ‘끝낸 습관’ 구역: 오늘 달성한 습관, 오늘 건너뛴 습관, 주 목표를 채운 주 N일 습관. 달성 카드가 먼저, 건너뜀 카드가 뒤.
5. ‘오늘 쉬는 습관 (n)’ 구역: 접힘 기본. 펼치면 기록 버튼 없는 카드. 쉬는 습관이 없으면 구역을 만들지 않는다.
6. 구역이 모두 비면 빈 상태: 상태 그림 `empty_habits`, ‘첫 습관을 만들어 볼까요?’, 버튼 ‘습관 추가’.

**카드 동작**

| 조작 | 결과 |
|---|---|
| 카드 탭 | 습관 상세 |
| 완료형 체크 버튼 | 체크 ↔ 취소. 달성이면 스티커 효과, 취소하면 토스트 ‘취소했어요’ |
| 수량형 ＋1 | 목표 단위 1만큼 증가(연타 모두 반영). 목표에 도달하는 순간 스티커 효과 |
| 수량형 ＋1 길게 누르기 | 직접 입력 시트(2절) |
| 시간형 재생 버튼 | 타이머 화면(3절) 열고 시작 |
| 시간형 카드의 ‘시간 입력’(메뉴) | 시간 기록 시트(2절) |
| 더보기(⋮) 또는 카드 길게 누르기 | 메뉴: 건너뛰기(건너뜀이면 ‘건너뛰기 취소’), 기록 초기화, 편집, 보관 |

**편집 모드(순서 변경):** 카드 왼쪽에 끌기 손잡이(≡)와 위·아래 버튼(48dp)이 나타난다. 모든 구역이 아닌 습관 전체 목록 순서(sortOrder)를 바꾼다. 상단 바 오른쪽에 ‘완료’ 버튼.

**문구**

| 상황 | 문구 |
|---|---|
| 건너뜀 카드 | ‘오늘은 쉬어요’ |
| 달성 칩 | ‘달성’ |
| 초과 달성 | ‘12/8잔 · 달성’ |
| 기록 취소 토스트 | ‘기록을 지웠어요’ + ‘실행 취소’ |
| 전부 달성 | ‘오늘 목표를 모두 달성했어요’ (state_all_done) |
| 쉬는 날 안내 | ‘오늘은 대상이 아니에요’ |

## 2. 기록 입력 시트

**수량 입력(하단 시트)**

- 제목: 습관 이름. 입력 칸(숫자, 단위 표시), 현재 기록 `3잔`을 기본값으로 채운다. 빠른 버튼 `＋1` `＋5` `－1`.
- 저장 버튼 ‘저장’(primary), 초기화 텍스트 버튼 ‘0으로 되돌리기’.
- 검증: 음수·소수 3자리 이상·범위 초과는 입력 칸 아래 ‘0 이상 소수 둘째 자리까지 입력해 주세요’.
- 이 시트는 총량을 그 값으로 바꾼다. 다른 곳에서 값이 바뀌어도 저장 시점의 입력값이 최종이다.

**시간 기록(하단 시트)**

- 분 입력(정수), 현재 기록 `20분`, 빠른 버튼 `＋10분` `＋30분` `－10분`.
- 초 단위 타이머 기록이 있으면 ‘타이머로 잰 12분 34초가 입력한 분으로 바뀌어요’를 body-s로 표시한다.
- 목표 대비 진행을 미리 보여준다: ‘30분 중 20분’.

**건너뛰기 확인:** 기록이 있는 날은 메뉴의 ‘건너뛰기’가 꺼져 있고 ‘기록이 있는 날은 건너뛸 수 없어요’를 설명으로 보여준다(비활성 대신 안내 문구).

## 3. 타이머

- 전체 화면. 상단 바: 닫기(×), 제목 습관 이름.
- 중앙: 큰 경과시간 `12:34`(display 확대 56sp, 주아), 아래 ‘오늘 20분 · 목표 30분’(body).
- 가운데 큰 원형 버튼(96dp): 시작 ↔ 일시정지. 일시정지 중에는 오른쪽에 ‘저장’(primary), 왼쪽에 ‘버리기’(text).
- 상단에 습관 색 스티커(72dp)가 있고, 실행 중에는 부분 기록 링처럼 목표 대비 진행을 천천히 채운다(저장 전 값 기준 표시).
- 저장 시 시트: ‘10월 12일에 12분 34초를 더할까요? 오늘 기록은 32분 34초가 돼요’ + ‘저장’ / ‘취소’.
- 다른 습관 타이머를 이미 쓰고 있으면 시작 시 대화상자: ‘독서 타이머가 켜져 있어요. 저장하거나 버려야 새로 시작할 수 있어요’ + ‘독서 열기’.
- 재부팅 후 복구: 상단 배너 ‘휴대폰이 다시 켜져서 마지막 기록 시점(12:00)에서 멈췄어요. 빠진 시간은 직접 더할 수 있어요’ + ‘시간 더하기’.
- 화면 켜짐 유지: 타이머 화면이 보이는 동안 화면을 꺼지지 않게 한다(설정에서 끌 수 있음은 M2).
- 알림: 실행 중에는 상태 표시줄에 지속 알림을 두지 않는다(M1 범위 밖, 습관 화면 카드에 경과시간 알약을 표시).

## 4. 습관 추가·편집

**화면 순서(위→아래)**

1. 상단 바: 닫기(×), 제목 ‘습관 추가’ / ‘습관 편집’, 오른쪽 ‘저장’(primary).
2. 미리보기 스티커(72dp). 탭하면 그림 선택 시트(그림 45개 격자 5열, 최근 선택 맨 위).
3. 이름(1~100자, 필수).
4. 색: 네 개의 원 스와치(48dp, 선택은 3dp 윤곽선 + 체크).
5. 유형: 세 칩 ‘완료’ ‘수량’ ‘시간’(생성 후 변경 불가, 편집에서는 잠금 표시와 ‘유형은 바꿀 수 없어요’).
6. 목표: 수량 = 목표량 + 단위(1~20자, 기본 ‘잔’ 등 자주 쓰는 단위 칩 6개: 잔 회 km 쪽 개 번), 시간 = 목표 분(정수), 완료 = 칸 없음.
7. 주기: 칩 ‘매일’ ‘요일 선택’ ‘주 N일’. 요일 선택은 요일 칩 7개, 주 N일은 1~7 스테퍼.
8. 시작일: 기본 오늘, 날짜 선택(오늘 또는 과거만). 생성 후 변경 불가.
9. 알림: ‘알림 시각’ 목록(최대 5개), ‘시각 추가’ 버튼. 이미 있는 시각은 ‘이미 있는 시각이에요’.
10. 메모(최대 20,000자, 선택).
11. 편집 화면 하단: 예약된 변경 안내 카드(‘10월 13일부터 8잔으로 바뀌어요’ + ‘예약 취소’), ‘보관’(danger 텍스트).

**추천 습관(새 습관일 때 상단 칩 줄):** 물 마시기 8잔(수량·매일), 독서 30분(시간·매일), 운동 주 3일(완료·주 3일), 스트레칭(완료·매일), 일기 쓰기(완료·매일), 일찍 자기(완료·매일). 선택하면 필드를 채우며 모두 수정할 수 있다.

**저장 규칙:** 이름이 비면 저장 버튼을 누를 때 이름 칸에 ‘이름을 입력해 주세요’. 변경 적용 시점은 제품 설계 5절을 따르며, 저장 후 토스트로 ‘내일부터 적용돼요’ 또는 ‘저장했어요’를 알린다.

## 5. 습관 상세

- 상단 바: 뒤로, 습관 이름, 더보기(편집·보관·기록 초기화·삭제).
- 머리: 스티커(72), 이름(title), 목표 한 줄(‘매일 8잔’, ‘월·수·금 30분’, ‘주 3일’), 예약된 변경 칩(‘10월 13일부터 8잔’).
- 통계 카드 3개 가로 배치: 현재 연속, 최장 연속, 달성률(‘이번 달’/‘전체’ 토글 알약). 각 카드 숫자는 display, 단위는 body-s(‘일’ 또는 ‘주’). 모드가 바뀐 경우 ‘일 단위’와 ‘주 단위’ 카드를 따로 보인다. 집계 없음은 ‘집계할 기록 없음’.
- 건너뛴 날 수: 통계 카드 아래 한 줄 ‘이 기간 건너뛴 날 2일’.
- 기록 달력: 월 이동 화살표, 5.6절 칸 규칙. 날짜를 탭하면 하단 시트: 날짜, 당시 목표, 기록량 입력(수량·시간·체크), 버튼 ‘건너뛰기’ ‘저장’. 미래·시작일 이전·비대상 날은 탭해도 시트 대신 토스트 ‘기록할 수 없는 날이에요’.
- 마일스톤 줄: 3·7·30·100일 스티커 4개. 얻은 것은 선명, 못 얻은 것은 점선 + ‘7일’ 문구.
- 메모(있을 때만), 알림 시각 목록(읽기 전용, 편집은 편집 화면).

## 6. 스티커 모음

- 진입: 습관 화면 요약 카드, 설정 없음.
- 상단: 이번 달 스티커 수 큰 숫자(‘이번 달 스티커 42개’), 월 이동.
- 본문: 습관별 행. 행 왼쪽 스티커(56)와 이름, 오른쪽에 이번 달 달성 수와 마일스톤 4칸.
- 아직 보관 해제하지 않은 보관 습관은 하단 ‘보관한 습관’ 구역에 함께 둔다.
- 마일스톤 칸을 탭하면 시트: ‘30일 연속 달성’, 달성 시기(‘10월 3일에 얻었어요’) 또는 ‘아직 15일 남았어요’.
- 모든 값은 기록에서 계산한다(별도 저장 없음).

## 7. 보관한 습관

- 목록: 카드(상태 칩 없음), 이름, ‘보관한 날 10월 5일’.
- 탭: 읽기 전용 상세(기록 달력 보기·과거 기록 수정 가능).
- 카드 더보기: ‘보관 해제’(‘다시 오늘 화면에 나타나요’ 확인), ‘영구 삭제’(danger, 대화상자 ‘이 습관과 모든 기록이 삭제돼요. 백업 파일이 없으면 되돌릴 수 없어요’ + ‘삭제’).
- 빈 상태: `empty_archive`, ‘보관한 습관이 없어요’.

## 8. 할 일

**상단 바:** 보기 이름(‘오늘’ 등)을 누르면 하단 시트에서 보기 선택(받은함·오늘·예정·전체·완료·휴지통, 사용자 목록, ‘목록 추가’). 오른쪽 검색·필터(태그) 아이콘.

**목록 행:** 왼쪽 체크 원(48dp), 제목(body 16), 아래 줄 body-s에 시간·목록·태그 칩, 오른쪽 우선순위 표시와 반복 아이콘. 완료는 제목에 취소선과 text-sub.

**오늘 보기:** ‘지난 일’(error-text 제목, 개수) 구역 → ‘오늘’ 구역. 날짜 없는 작업은 나타나지 않는다.

**빈 상태:** `empty_tasks`, ‘오늘 할 일이 없어요’, ‘할 일 추가’. 검색 없음은 `empty_search`, ‘찾는 결과가 없어요’.

**완료 동작:** 체크하면 행이 접히며 토스트 ‘완료했어요’ + ‘실행 취소’(반복 작업은 ‘다음 일정은 10월 13일이에요’).

## 9. 빠른 추가

- 하단 시트. 제목 입력(포커스 자동), 아래 칩 줄: 날짜(오늘·내일·날짜 선택), 목록, 우선순위. 오른쪽에 ‘저장’(primary), 왼쪽 ‘자세히’(작업 상세로 이동).
- 제목이 공백이면 저장 시 ‘제목을 입력해 주세요’.
- 캘린더에서 열면 날짜 칩이 선택 날짜로 채워진다.

## 10. 작업 상세

위→아래: 제목(수정 가능), 체크 완료, 메모, 체크리스트(항목 추가·삭제·체크), 날짜·시간, 반복(‘매일’ 등 한 줄 요약 → 반복 시트), 알림(‘10분 전’ 등 칩 최대 5), 목록, 태그, 우선순위 4칩, 하단 ‘삭제’(휴지통으로).

- 반복 시트: 단위(일·주·월·년), 간격 스테퍼, 요일 선택(주), 종료일(선택).
- 종일 작업의 알림은 ‘오전 9:00(설정에서 바꿔요)’로 표시한다.
- 반복 작업에서 선택한 미래 회차를 열면 ‘이 회차는 아직 완료할 수 없어요’를 완료 영역에 표시한다.

## 11. 캘린더

- 상단: 월 이동, ‘오늘’ 버튼. 본문 위쪽 월 달력(5.6절), 아래쪽 선택 날짜의 작업 목록(8절 행과 같음).
- 선택 날짜가 없는 월에서는 오늘을 선택한다. 날짜를 길게 누르면 그 날짜로 빠른 추가.
- 습관 달성 표시는 이 달력에 넣지 않는다(습관 상세 달력과 구별).

## 12. 설정

구역 순서와 항목:

1. 화면: 테마(시스템·밝게·어둡게), 달성 효과 진동(스위치).
2. 알림: 알림 권한 상태(허용·꺼짐 + ‘설정 열기’), 정확한 시각 알림 상태, 절전 예외 상태(‘예외가 아니면 알림이 늦을 수 있어요’ + ‘등록 안내’), 하루 요약(스위치, 시각), 종일 작업 알림 시각(기본 오전 9:00).
3. 데이터: 백업 저장(‘평문 JSON 파일로 저장돼요’), 백업에서 복원, 스냅샷으로 되돌리기(스냅샷 날짜 표시).
4. 업데이트: 현재 버전 `Harugyeol v1.0.0 (1)`, ‘지금 확인’, 진행 상태(11절).
5. 정보: 오픈소스 라이선스(글자체·그림 출처 포함), 앱 정보(패키지명 `com.bossxor.harugyeol`, 버전).

- 하루 요약을 처음 켤 때 시각 선택 시트가 먼저 뜬다(기본 20:30), 확인 후 활성화한다.

## 13. 백업·복원 화면

- 백업 저장: 시스템 파일 저장 창으로 이동. 저장 완료 토스트 ‘백업을 저장했어요’.
- 복원: 파일 선택 → 검사 중 → 결과 시트. 현재/복원 항목 수 비교표(습관·기록·작업), ‘현재 데이터가 모두 바뀌어요’, 버튼 ‘교체해서 복원’(danger), ‘취소’.
- 오류 시트: ‘파일을 읽을 수 없어요. 다른 백업 파일을 선택해 주세요.’ / ‘이 앱보다 새 버전의 백업이에요. 앱을 업데이트해 주세요.’
- 실행 중 타이머가 있으면 먼저 ‘타이머를 저장하거나 버려야 해요’ 시트.

## 14. 휴지통

- 행: 제목, ‘삭제한 날’. 탭하면 ‘복구’ / ‘영구 삭제’ 시트.
- 상단 더보기: ‘휴지통 비우기’(danger 확인 대화상자). 빈 상태: `empty_trash`, ‘휴지통이 비어 있어요’.

## 15. 앱 업데이트 표시

| 상태 | 표시 | 동작 |
|---|---|---|
| 확인 중 | 없음(조용히) | 설정 ‘지금 확인’에서만 스피너 |
| 다운로드 중 | 습관·할 일 화면 상단에 얇은 배너 ‘새 버전을 받는 중이에요 (45%)’ | 앱 사용 가능, 배너 닫기 없음 |
| 설치 준비 | 배너 ‘설치를 준비하고 있어요’ | 데이터 스냅샷 저장 |
| 허용 필요 | 시트 ‘설치 허용이 필요해요’ + ‘설정 열기’ | 시스템 화면 이동 |
| 내부 설치 실패 | 시트(`update` 그림) ‘앱에서 바로 설치할 수 없어요. 다운로드 폴더에 새 버전과 백업 파일을 저장했어요’ + ‘설치 화면 열기’ | 2단계 직접 설치 |
| 실패 | 설정 ‘지금 확인’ 시 ‘업데이트를 확인하지 못했어요. 인터넷 연결을 확인해 주세요’ | 다음 실행에서 다시 시도 |
| 최신 | 설정 ‘지금 확인’ 시 ‘최신 버전이에요’ | — |

## 16. 알림 모양

| 알림 | 제목 | 본문 | 액션 |
|---|---|---|---|
| 습관(완료형) | 습관 이름 | ‘오늘 아직 기록이 없어요’ | 완료 |
| 습관(수량·시간형) | 습관 이름 | ‘3/8잔 · 5잔 남았어요’ | 기록하기(해당 날짜 입력 시트) |
| 하루 요약 | ‘오늘 3/5 달성’ | ‘남은 습관: 독서 20/30분, 운동’ | 열기 |
| 전부 달성 요약 | ‘오늘 목표를 모두 달성했어요’ | 달성한 습관 수 | 열기 |
| 작업 | 작업 제목 | ‘오늘 오후 3:00’ 등 | 완료, 10분 뒤 |

- 작은 아이콘은 하루결 해 모양 실루엣, 큰 아이콘은 습관 스티커(습관 알림만).
- 잠금 화면에서는 제목만 표시하고 본문을 숨긴다.

## 17. 첫 실행

- 온보딩 화면 없이 습관 화면이 빈 상태로 열린다(`empty_habits`, ‘첫 습관을 만들어 볼까요?’). 버튼 ‘습관 추가’ 아래에 추천 습관 칩 3개를 보인다.
- 알림 권한은 첫 알림 시각을 추가할 때 이유 안내 시트(‘정해 둔 시각에 알려 드려요’) 후 요청한다.
- 업데이트 확인은 첫 실행에도 같다.
