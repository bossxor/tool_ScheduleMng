# 위젯·잠금화면 설계 v0.1

기준일: 2026-10-12. 사용자 요청으로 기본 위젯과 잠금화면 사용을 M1에 추가한다. 목록·빠른 추가·위젯 직접 기록은 후속 확장으로 유지한다.

## 범위와 표시

| 위치 | 표시 | 동작 |
|---|---|---|
| 홈 화면 오늘 요약 | 날짜, 오늘 습관 달성/대상 수, 오늘·지난 미완료 할 일 개수 | 앱 열기 |
| 지원되는 잠금화면 위젯 호스트 | 같은 요약 개수, 작업 제목·메모·습관 이름 없음 | 시스템 잠금 해제 후 앱 열기 |
| 잠금화면 작업 알림 | 기본 공개 버전은 앱 이름과 잠금 해제 안내 | 완료·10분 미루기 선택 시 인증 후 실행 |

`home_screen|keyguard` 선언은 해당 위치에서 사용할 수 있음을 뜻한다. 실제 잠금화면 위젯 선택·배치는 제조사와 시스템 호스트의 지원이 필요하다. 앱이 Samsung 잠금화면 편집기에 강제로 추가하거나 잠금을 우회하지 않는다. 미지원 기기는 홈 화면 위젯과 잠금화면 알림을 사용한다. AOD·Now Bar·전용 전체 잠금화면은 이번 범위에 포함하지 않는다.

## 모양과 추가 흐름

- 권장 4×2 셀, 최소 250×150dp. 실제 셀 배치는 호스트에 따라 달라지며 Samsung 실기기에서는 4×3으로 확인했다. 크기 조절 가능. 밝은 배경·진한 글자·둥근 카드.
- 간단한 텍스트와 높이 48dp 앱 열기 버튼. 화면 읽기 도구로 읽을 수 있다.
- 설정 → 위젯·잠금화면 → 홈 화면 위젯 추가 → 시스템의 배치 확인. API 미지원 호스트는 홈 화면 길게 누르기 안내.
- 초기 미리보기는 예시 문구만 표시한다. 데이터 오류는 확인 안내와 앱 열기로 처리하고 원본 파일을 변경하지 않는다.

## 저장·갱신

- 외부 라이브러리 없이 AppWidgetProvider와 RemoteViews를 사용한다. AppStore를 원본으로 삼고 위젯 전용 데이터 저장소는 만들지 않는다.
- 저장 성공 뒤 StateFlow 관찰자가 알림과 위젯을 갱신한다. 화면·알림 액션·복원 모두 같은 경로를 쓴다.
- 생성, 날짜·시각·시간대 변경, 주기 갱신 때 다시 계산한다. 시스템 주기는 30분 요청이며 OS에서 지연될 수 있다. 표시 날짜를 함께 보여주며 정확히 자정 갱신은 보장하지 않는다.
- 네트워크·로그인·새 권한은 필요하지 않다. 재부팅 후 첫 잠금 해제 전 내부 데이터 읽기는 지원하지 않는다(Direct Boot 대상 아님).

## 잠금화면 알림

- 작업 알림에 VISIBILITY_PRIVATE와 내용 없는 publicVersion을 적용한다. 실제 노출은 사용자의 Android 알림 설정에 따른다.
- 완료·10분 미루기는 setAuthenticationRequired(true)로 시스템 인증을 요구한다. 수신기에서도 잠금 상태를 확인한다.
- 작업 ID와 회차 날짜를 전달하고 오래된 액션은 상태와 새 회차 알림을 변경하지 않는다.
- 완료는 회차 기록과 다음 예정일을 원자적으로 바꾼다. 미루기는 snoozedUntil을 파일에 보존해 종료·재부팅 후 다시 예약한다.
- 시간대 변경 시 같은 현지 시각으로 다시 계산하고 이미 지난 알림을 다시 쌓지 않는다.

## 수용 기준

- 덮어 설치·기존 schemaVersion 1 파일 및 백업 읽기·기록 유지.
- 위젯 추가→요약 표시→데이터 변경 후 갱신→앱 열기.
- 제목·메모·습관 이름이 위젯과 잠긴 알림 공개 버전에 노출되지 않음.
- 지원 기기에서 잠금화면 배치·인증 후 액션 확인. 미지원 기기에서 홈 위젯·알림 대체.
- 여러 위젯·크기 변경·재부팅·날짜·시간대·큰 글씨·TalkBack 확인.
- 반복 월말·윤년·요일·종료일·늦은 완료·중복 완료·미루기 보존을 단위 테스트로 검증.

## 후속 확장

오늘 할 일 목록, 선택 습관 기록, 빠른 추가, 타이머, 위젯 구성과 테마는 후속 설계로 확장한다. 잠금 상태의 직접 기록 허용 여부는 사용자 선택과 호스트 동작을 확인해 결정한다.

## 공식 근거

- [AppWidgetProviderInfo](https://developer.android.com/reference/android/appwidget/AppWidgetProviderInfo): 홈·keyguard 카테고리 및 호스트 처리.
- [Notification.Action.Builder](https://developer.android.com/reference/android/app/Notification.Action.Builder#setAuthenticationRequired(boolean)): 인증 후 액션 전달.
