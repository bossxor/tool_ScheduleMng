# 알림·저장·날짜·타이머 5개 수정

기준일: 2026-10-13. 브랜치: `codex/fix-five-verified-issues`.
이전 재현 기준 코드는 `793991b`이며 [검증 보고](verification-20261013.md)는 당시 이력으로 유지한다.

## 변경

1. **미수신 알림 유지**: 전체 예약 취소를 제거했다. 예약 키와 시각이 같은 OS 예약을 유지하며 수정·삭제된 예약만 교체한다. 예정 시각이 지난 작업도 기존에 예약했던 동일 회차라면 유지한다. 수신 시 예약 키·시각을 소모해 중복 수신이 다음 예약을 지우지 않게 한다. 앱 시작·재부팅에는 OS 예약을 복구한다.
2. **차단된 요약 채널 처리**: 요약 설정과 Android 채널 허용 상태를 함께 확인한다. 요약 채널이 차단됐으면 같은 시각의 습관 예약을 유지한다. 채널 상태 변경 브로드캐스트와 앱 복귀에서 재검사한다.
3. **20MiB 쓰기 한도**: 저장과 백업 내보내기도 UTF-8 직렬화 크기를 검사한다. 한도 초과는 임시 파일 생성 전에 거부해 기존 파일·메모리 상태를 유지한다. 화면에는 기록을 정리해야 한다는 안내를 제공한다.
4. **날짜 경계**: 활동 중 날짜·시각·시간대 변경을 수신해 화면 날짜를 갱신한다. 실제 기록과 완료 처리 직전에도 현재 날짜를 확인한다. 과거 날짜를 명시한 상세 기록 수정은 유지한다.
5. **타이머 이탈 보존**: 타이머 화면을 떠날 때와 Activity.onPause에서 마지막 측정량을 보존한다. 기존 Application의 IO 범위를 사용해 화면이 사라져도 저장을 이어간다. 다른 세션으로 바뀐 경우 오래된 요청은 그 세션에 적용하지 않는다.

파일 데이터 형식·패키지 ID·앱 버전·사용자 서명 키는 변경하지 않았다. 새 라이브러리는 추가하지 않았다.

## 검증 상태

- `gradlew.bat testDebugUnitTest assembleRelease lintRelease`: 통과.
- 단위 테스트 95개, 실패·오류 0. 기존 87개에 관련 회귀 테스트 8개를 추가했다.
- 릴리스 lint: 오류 0, 경고 21. 경고 전체를 해결했다고 보고하지 않는다.
- 릴리스 빌드는 R8 축소를 포함하며 현재 컴퓨터에는 사용자 서명 설정이 없어 unsigned APK다. 설치·공개 릴리스는 하지 않았다.
- 수정 후 Android 런타임 검증은 진행 중이다. USB가 분리되어 S26 Ultra 재검증은 아직 통과 처리하지 않는다.
- 로컬 Android 13 소프트웨어 에뮬레이터는 가속 드라이버 없이 부팅을 완료하지 못해 종료했다. 시스템 가속 드라이버나 보안 설정은 변경하지 않았다.
- GitHub Actions의 Android 13 에뮬레이터에서 별도 패키지로 런타임 회귀 검증을 실행한다. 결과 확인 전 통과로 표시하지 않는다.

## 런타임 검증 소스

[verification/20261013-fixed](../verification/20261013-fixed)는 실제 제품 Application·알림 예약기·MainActivity·TimerScreen을 사용한다.
검증 앱 ID는 `com.bossxor.harugyeol.verification`이고 자동 백업을 제외한다. 합성 데이터만 사용하며 종료 시 앱을 제거한다.
기본 제품 빌드에는 진단 소스가 포함되지 않는다.

검증 항목은 지연 예약 유지, 변경 전 콜백 거부, 시작 시 예약 복구, 삭제 후 취소, 하루 알림 소모·다음날 재예약, 차단 요약에서 개별 알림 게시, 오래된 날짜 갱신, 30초 이전 화면 이탈 및 백그라운드 보존이다.
시스템 시계와 사용자 개인 앱의 파일·알림 설정은 바꾸지 않는다. 날짜와 부팅 변화는 입력/이벤트로 주입한다.
