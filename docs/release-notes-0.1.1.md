# 하루결 0.1.1

개인용 Android 습관·할 일 관리 앱 하루결의 첫 공개 배포입니다. Android 13 이상을 지원하며 로그인 없이 기기에 기록을 저장합니다.

## 포함된 기능

- 완료·수량·시간 습관, 타이머, 기록 달력·통계·스티커 모음
- 목록·태그·체크리스트·반복 할 일·검색·휴지통
- 습관·할 일 알림, 인증 후 완료·10분 미루기, 오늘 요약 홈 위젯
- 파일 백업·복원·스냅샷, 테마·큰 글씨 습관 카드 배치
- 캘린더의 어제/오늘 조회 및 날짜별 습관 기록
- GitHub 릴리스 업데이트, 다운로드 크기·서명·버전 검사

## 설치

Harugyeol-0.1.1.apk를 내려받아 설치하세요. 기존 앱이 있으면 삭제하지 않고 덮어 설치합니다. 기록 백업을 먼저 권장합니다. 필요한 경우 파일을 연 앱의 설치 권한과 하루결 알림 권한을 허용하세요.

SHA256SUMS-0.1.1.txt에서 체크섬을 확인할 수 있습니다. 패키지 com.bossxor.harugyeol, versionCode 3.

## 검증 및 지원 범위

87개 단위 테스트와 R8 서명 릴리스 빌드 통과. Galaxy S26 Ultra에서 주요 흐름·기록 유지·파일 백업/복원·200% 주요 화면을 확인했습니다. Android 13 별도 기기, TalkBack 전체 음성 탐색, 제조사별 잠금화면 위젯 지원은 추가 확인 대상입니다. 알림은 기기의 권한·절전 설정에 따라 지연될 수 있습니다.

실제 GitHub 릴리스 업데이트 후 0.1.1 설치·기록/일시정지 타이머 유지·최신 버전 표시와 타이머 재부팅 복구를 추가 확인했습니다.
