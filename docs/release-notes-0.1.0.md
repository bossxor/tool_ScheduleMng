# 하루결 0.1.0 — M1 릴리스 준비

- Android 13 이상. 패키지 com.bossxor.harugyeol, versionCode 2.
- 습관 기록·통계·타이머·알림, 시작일·메모·그림·추천 습관·스티커 모음.
- 할 일 목록·태그·체크리스트·검색·휴지통, 반복·완료 이력·되돌리기·캘린더.
- 오늘 요약 위젯, 잠금 해제 인증 후 알림 완료·10분 미루기.
- 테마·달성 효과·라이선스, JSON 백업·복원·스냅샷·손상 데이터 복구.
- 다운로드 크기·패키지·버전·서명 검사 및 업데이트 설치 대체 경로.
- schema 1 원문은 최초 변경 전 내부 migration-v1.json으로 보존. 복원 후보 원문도 별도 보존.

## 설치

기존 앱을 삭제하지 말고 Harugyeol-0.1.0.apk를 열어 덮어 설치하세요. Android에서 요청하면 해당 파일 앱의 설치 권한을 허용하세요. 앱 알림 권한과 정확한 알람·배터리 제한 상태는 설정에서 확인하세요. 설치 전 설정 → 데이터 → 백업을 권장합니다.

## 공개 전 확인

로컬 단위 테스트와 서명 릴리스 빌드·실기기 덮어 설치 결과는 progress.md를 확인하세요. 실제 GitHub 공개 릴리스를 통한 자동 업데이트, Android 13 실기기, TalkBack, 삼성 잠금화면 위젯 호스트·재부팅은 별도 환경 검증이 남아 있습니다. 공개 릴리스는 아직 생성하지 않았습니다.
