## 2. 구현된 것

### 기반
- Android 프로젝트: AGP 9.4.1, Kotlin 2.4.21, Compose BOM 2026.09.00, Gradle 9.8.1, compile/targetSdk 37, minSdk 33. 패키지 `com.bossxor.harugyeol`.
- 저장: 앱 내부 `data.json` 하나. 임시 파일 쓰기 → `fsync` → 원자적 이동, 변경은 Mutex로 직렬화. 읽을 수 없거나 더 새 버전인 파일은 덮어쓰지 않고 오류 화면을 보여준다.
- 서명: 저장소 밖 키(`C:\Users\N-052\harugyeol-keys\`)로 release APK에 서명한다.
- CI: GitHub Actions 워크플로(`.github/workflows/build.yml`)가 있으나 아직 실행 결과를 확인하지 않았다.

### 디자인
- 글자체: 주아(제목·큰 글자), Pretendard(본문·숫자)를 앱에 포함. 라이선스 파일은 `assets/fonts/`.
- 색상 토큰: 습관 4색, 밝은·어두운 모드 값(`ui/Theme.kt`). 컴포넌트: 오프셋 그림자 카드, 알약 버튼, 스티커 원, 텍스트 입력.
- 스티커 상태: 달성(채움+체크 배지), 부분(진행 링), 미기록(점선), 건너뜀, 쉬는 날. 그림 자리에는 이름 첫 글자.

### 습관·체크인
- 목표 유형 완료·수량(소수 둘째 자리)·시간(분 입력, 초 저장), 주기 매일·요일 선택·주 N일.
- 기록: `＋1`(연타 모두 반영), 직접 입력, 초기화, 완료 체크, 건너뛰기. 미래·시작일 이전·비대상 날짜·범위 초과 거부.
- 오늘 화면: 요약 카드와 주간 띠, 구역(오늘 할 습관·이번 주 목표·끝낸 습관·오늘 쉬는 습관), 순서 변경(▲▼), 보관함.
- 상세: 현재·최장 연속, 달성률(이번 달/전체), 건너뛴 날 수, 월 기록 달력, 과거 날짜 수정·건너뛰기, 예약된 목표 변경 표시·취소.
- 편집: 이름·색·주기·목표량·알림 시각. 기록이 없으면 즉시, 있으면 내일(주 목표는 다음 월요일)부터 적용. 유형·단위는 잠금.
- 보관·보관 해제·영구 삭제(확인창). 타이머가 켜진 습관은 보관·삭제 불가.
- 통계 규칙: 비대상 날·건너뛴 날은 연속을 끊지 않음, 진행 중인 오늘·주는 끊지 않음, 주 목표는 건너뛴 날만큼 축소, 달성률은 어제까지.

### 타이머
- 시간 목표 습관에서 시작·일시정지·이어서·저장·버리기. 앱 종료 후에도 복구된다.
- 재부팅은 `BOOT_COUNT`로 감지해 마지막 보존 시점(30초마다 저장)에서 일시정지하고 안내한다.
- 저장은 세션 ID 확인 후 초 단위로 한 번만 더한다. 1초 미만은 저장하지 않는다.

### 알림
- 습관별 시각 최대 5개, 하루 요약(기본 20:30, 설정에서 켬). 요약과 같은 시각의 개별 알림은 예약하지 않는다.
- 매일 같은 시각에 울리는 알람을 두고, 수신할 때 오늘 상태(대상·미달성·보관·건너뜀)를 다시 확인해 표시한다.
- 완료형 습관 알림에 ‘완료’ 버튼(알림에 담긴 날짜로 기록).
- 앱 시작·데이터 변경·재부팅·시간 변경·앱 업데이트 때 다시 예약한다. `USE_EXACT_ALARM` 선언.
- 설정 화면: 알림 권한 요청, 하루 요약 켜기·시각, 배터리 제한 해제 안내.

## 4. 아직 없는 것 (설계 대비)

### 화면·기능
- 하단 메뉴(습관·할 일·캘린더·설정)가 없다. 지금은 습관 화면 상단의 텍스트 버튼(순서·보관함·설정)으로 이동한다.
- 할 일(목록·태그·체크리스트·휴지통·검색), 반복 일정, 월 캘린더, 작업 알림.
- 습관 시작일 선택(지금은 항상 오늘), 습관 그림 선택, 스티커 모음 화면과 마일스톤 스티커(3·7·30·100일).
- 추천 습관 6개 중 3개만 있다(물 마시기·독서·스트레칭).
- 알림: 수량·시간형의 ‘기록하기’ 액션, 종일 작업 알림 시각 설정, 누락 알림 표시.
- 타이머: 화면 켜짐 유지, 다른 습관 타이머 전환 안내(지금은 오류 토스트만).
- 백업·복원, 내부 스냅샷, 스냅샷으로 되돌리기.
- 앱 업데이트(실행 시 확인·자동 다운로드·내부 설치·직접 설치 대체).
- 테마 선택(지금은 시스템 설정을 따름), 달성 효과 진동, 달성 시 스티커 전환 효과.
- 오픈소스 라이선스 화면, 앱 정보.

### 디자인 자원
- 습관 그림 45개, 마일스톤 4개, 상태 그림 7장, 최종 앱 아이콘(지금은 임시 해+체크).
- `assets/LICENSES.md` 출처 대장.

### 검증
- 어두운 모드·글자 확대(200%)·TalkBack 확인 전.
- GitHub Actions 첫 실행 결과 확인 전.
- 습관 편집·순서·보관 화면의 실기기 조작, 시스템 시간 선택창을 통한 알림 시각 추가.
- 알림 실제 발송과 삼성 절전 환경에서의 지연.

## 5. 알려진 한계·결정 필요

- 시간 습관 카드는 분 단위로 내림해 표시한다(20분 41초 → `20/30분`).
- 상태 표시줄은 edge-to-edge로 처리했으나 어두운 모드 화면 확인은 못 했다.
- release APK가 23MB다. 코드 축소(R8)를 켜지 않았다. 출시 단계에서 적용한다.
- 폰 알림 설정 허용은 사용자가 직접 해야 한다(앱이 대신 허용할 수 없다).
- 데이터 파일은 변경마다 전체를 다시 쓴다. 현재 규모에서는 문제가 없고, 느려지면 연도별 분리를 검토한다.
- 저장 파일 구조는 `schemaVersion` 1이다. 출시 전에는 필드를 바꾸면 이전 파일을 읽지 못할 수 있다(출시 후에는 변환 함수로 처리).

## 7. 개발 환경 요약

- 필요 도구: JDK 17, Android SDK(platform 37.0, build-tools 37.0.0), `adb`, Git.
- 빌드·테스트: `./gradlew testDebugUnitTest assembleRelease` (`JAVA_HOME`은 JDK 17).
- 서명 키: `~/harugyeol-keys/keystore.properties`(또는 `-Pharugyeol.keystoreProperties=<경로>`). 파일이 없으면 release는 서명 없이 빌드된다.
- 설치: `adb install -r app/build/outputs/apk/release/app-release.apk`.
- 기기 연결이 끊기면 `adb kill-server` 후 `adb start-server`로 재시작한다.
