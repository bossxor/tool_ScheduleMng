## 반복 일정·작업 알림·위젯 추가 (2026-10-12)

현재 작업 브랜치는 `codex/continue-m1`이다. 이후 절의 36/47개 테스트와 미착수 표는 이전 구현 이력이다.

- 작업 시각·종일 시각 설정, 일·주·월·년 반복, 간격·선택 요일·종료일, 회차 완료 이력과 직후 되돌리기를 추가했다.
- 월말·윤년 원래 날짜 복귀, 늦은 완료의 다음 회차 이동, 중복·오래된 회차 액션 무시, 다른 변경 후 되돌리기 거부를 검증했다. 반복 해제 후에도 과거 완료 이력을 유지한다.
- 캘린더는 조회 월의 미래 회차를 계산하고 완료 이력을 표시한다. 미래 회차·과거 완료 회차의 체크 버튼은 비활성화한다.
- 작업별 최대 5개 알림(정시·10/30/60분 전·1일 전), 현재 회차만 예약, 완료·삭제·수정 후 취소, 10분 미루기 보존과 재부팅·시간대 재예약을 구현했다.
- 작업 알림에는 완료·10분 미루기 액션과 해당 작업 열기를 제공한다. 잠금화면은 내용 없는 공개 버전과 시스템 인증 후 액션을 사용한다.
- 기본 오늘 요약 위젯: 습관 달성/대상 수, 오늘·지난 할 일 개수, 앱 열기. 설정에서 홈 화면에 추가하며 저장 성공·날짜 변경·시스템 주기로 갱신한다. 홈·지원되는 keyguard 호스트를 선언한다.
- [위젯·잠금화면 설계](widgets-lockscreen-design.md)를 추가하고 제품·기술·화면·개발 계획의 M1 범위에 반영했다. 실제 잠금화면 위젯 배치는 제조사 호스트 지원이 필요하다.
- 기존 파일의 새 필드는 기본값으로 읽고 백업에서 반복·회차·알림·미루기를 검증·보존한다. 추가 단위 테스트 16개를 작성했고 기존 47개와 합계 63개가 통과했다. testDebugUnitTest·assembleRelease 성공 및 최종 APK 덮어 설치를 확인했다.
- 실기기: release 덮어 설치·기존 습관 3개·2/3 달성 유지, 매일 반복 작업 저장, 15:04 정시 작업 알림 발송, 완료 후 내일 회차 이동·오늘 회차 되돌리기 확인.
- 홈 위젯 배치·습관 2/3와 할 일 1개 표시, 완료 후 할 일 0개 갱신, 위젯의 앱 열기 확인. 영구 삭제 확인창까지 점검하고 검증용 작업은 삭제했다.
- 위젯 선택기에서 초기 레이아웃 미리보기 오류가 보여 개인 데이터 없는 정적 미리보기 자원을 추가했다. 최종 재설치 후 선택기의 오류 문구가 사라진 것을 확인했다. Samsung 홈은 4×3 크기로 배치했다(권장 셀 크기는 호스트에 따라 달라짐).

남은 실기기 검증: 잠금 상태의 알림 공개 버전·인증 후 완료/미루기, 10분 미루기 실제 재발송·재부팅, Samsung 잠금화면 위젯 선택 가능 여부, 여러 위젯·크기 변경·날짜 경계·큰 글씨·TalkBack. 이 항목들은 구현 또는 단위 테스트 결과만으로 실기기 통과 처리하지 않는다.

## 2026-10-12 후속 작업 (로컬 `codex/continue-m1`)

아래의 기존 단계 표·실기기 결과는 `main` 기준 이력이다. 이번 작업 브랜치의 변경은 다음과 같다.

- 중복 빌드 설정과 캐시만 남은 `tool_ScheduleMng` 폴더를 삭제했다.
- 로컬 `wip/tasks-backup-update` 구현을 최신 main 위에 반영했다. 하단 메뉴, 기본 할 일 CRUD·완료·휴지통, 월 캘린더, 백업·복원·스냅샷, 업데이트 구현을 포함한다. 기존 높은 중요도 알림 채널도 유지한다.
- 할 일 제목·메모 검색(완료 포함 선택), 중복 완료 요청과 휴지통의 늦은 완료 요청 방지를 추가했다. 영구 삭제·휴지통 비우기 확인창과 탭 전환 시 검색·필터·캘린더 월/선택일 보존도 보완했다.
- 시작·파일 복원·스냅샷 복원에 같은 검증을 적용했다. 20MiB 입력 제한, 목표 주기·유형·단위·중복 ID/기록/알림·타이머 참조·메모 길이를 검증하며 잘못된 복원은 기존 파일을 유지한다.
- 스냅샷을 원자적으로 저장한다. 업데이트용 스냅샷은 잠금 안에서 현재 데이터를 읽어 동시 변경을 덮어쓰지 않는다.
- 업데이트에서 잘못된 버전·사전 릴리스·여러 APK를 거부하고 패키지·버전 코드 외에 서명을 사전 확인한다. 불완전 다운로드와 대체 설치 전 백업 저장 실패도 중단한다.
- 단위 테스트 11개 추가: 보기·정렬·검색·중복 완료, 백업 왕복·잘못된 복원 무변경·과대 입력·스냅샷 왕복, 버전 비교·릴리스 선택.
- 실기기: 갤럭시 S26 울트라에 release 덮어 설치 성공. 기존 습관 3개·오늘 2/3 달성·물 8/8잔·독서 20/30분 유지. 검증용 할 일 추가→오늘 목록·캘린더 반영→완료→휴지통→복구(완료 유지)→영구 삭제 확인. 테스트 데이터 정리 완료.
- 마지막 UI 보완(영구 삭제 확인·탭 상태 보존)과 대체 설치 백업 실패 처리까지 release 빌드·단위 테스트 대상에 포함했다. ADB 재연결 후 마지막 APK 덮어 설치·정상 실행·기존 기록 유지와 탭 전환 후 완료 필터 유지까지 확인했다. 영구 삭제 확인창과 캘린더 선택 유지의 조작 검증은 남아 있다.
- 검증 명령: `gradlew.bat testDebugUnitTest assembleRelease`. release 빌드와 단위 테스트 47개(기존 36+추가 11) 통과.

M1 전체 완료는 아니다. 목록·태그·체크리스트·반복·작업 알림, 습관 시작일·스티커 자원, 접근성, 실제 릴리스를 통한 자동 업데이트 검증은 이어서 필요하다. 백업 파일 선택·교체 및 설치 권한·실패 대체 흐름도 실기기 종단 간 검증이 필요하다. 타이머가 남은 복원에서 저장/버리기 선택 흐름은 보완 대상이다.

- Android 프로젝트: AGP 9.4.1, Kotlin 2.4.21, Compose BOM 2026.09.00, Gradle 9.8.1, compile/targetSdk 37, minSdk 33. 패키지 `com.bossxor.harugyeol`.

### 디자인
- 글자체: 주아(제목·큰 글자), Pretendard(본문·숫자)를 앱에 포함. 라이선스 파일은 `assets/fonts/`.
- 색상 토큰: 습관 4색, 밝은·어두운 모드 값(`ui/Theme.kt`). 컴포넌트: 오프셋 그림자 카드, 알약 버튼, 스티커 원, 텍스트 입력.
- 스티커 상태: 달성(채움+체크 배지), 부분(진행 링), 미기록(점선), 건너뜀, 쉬는 날. 그림 자리에는 이름 첫 글자.

### 습관·체크인
- 목표 유형 완료·수량(소수 둘째 자리)·시간(분 입력, 초 저장), 주기 매일·요일 선택·주 N일.
- 기록: `＋1`(연타 모두 반영), 직접 입력, 초기화, 완료 체크, 건너뛰기. 미래·시작일 이전·비대상 날짜·범위 초과 거부.
- 오늘 화면: 요약 카드와 주간 띠, 구역(오늘 할 습관·이번 주 목표·끝낸 습관·오늘 쉬는 습관), 순서 변경(▲▼), 보관함.
- 상세: 현재·최장 연속, 달성률(이번 달/전체), 건너뛴 날 수, 월 기록 달력, 과거 날짜 수정·건너뛰기, 예약된 목표 변경 표시·취소.
- 편집: 이름·색·주기·목표량·알림 시각. 기록이 없으면 즉시, 있으면 내일(주 목표는 다음 월요일)부터 적용. 유형·단위는 잠금.
- 보관·보관 해제·영구 삭제(확인창). 타이머가 켜진 습관은 보관·삭제 불가.
- 통계 규칙: 비대상 날·건너뛴 날은 연속을 끊지 않음, 진행 중인 오늘·주는 끊지 않음, 주 목표는 건너뛴 날만큼 축소, 달성률은 어제까지.

### 타이머
- 시간 목표 습관에서 시작·일시정지·이어서·저장·버리기. 앱 종료 후에도 복구된다.
- 재부팅은 `BOOT_COUNT`로 감지해 마지막 보존 시점(30초마다 저장)에서 일시정지하고 안내한다.
- 저장은 세션 ID 확인 후 초 단위로 한 번만 더한다. 1초 미만은 저장하지 않는다.

### 알림
- 습관별 시각 최대 5개, 하루 요약(기본 20:30, 설정에서 켬). 요약과 같은 시각의 개별 알림은 예약하지 않는다.
- 매일 같은 시각에 울리는 알람을 두고, 수신할 때 오늘 상태(대상·미달성·보관·건너뜀)를 다시 확인해 표시한다.
- 완료형 습관 알림에 ‘완료’ 버튼(알림에 담긴 날짜로 기록).
- 앱 시작·데이터 변경·재부팅·시간 변경·앱 업데이트 때 다시 예약한다. `USE_EXACT_ALARM` 선언.
- 설정 화면: 알림 권한 요청, 하루 요약 켜기·시각, 배터리 제한 해제 안내.

## 5. 알려진 한계·결정 필요

- 시간 습관 카드는 분 단위로 내림해 표시한다(20분 41초 → `20/30분`).
- 상태 표시줄은 edge-to-edge로 처리했으나 어두운 모드 화면 확인은 못 했다.
- release APK가 23MB다. 코드 축소(R8)를 켜지 않았다. 출시 단계에서 적용한다.
- 폰 알림 설정 허용은 사용자가 직접 해야 한다(앱이 대신 허용할 수 없다).
- 데이터 파일은 변경마다 전체를 다시 쓴다. 현재 규모에서는 문제가 없고, 느려지면 연도별 분리를 검토한다.
- 저장 파일 구조는 `schemaVersion` 1이다. 출시 전에는 필드를 바꾸면 이전 파일을 읽지 못할 수 있다(출시 후에는 변환 함수로 처리).

## 7. 개발 환경 요약

- 필요 도구: JDK 17, Android SDK(platform 37.0, build-tools 37.0.0), `adb`, Git.
- 빌드·테스트: `./gradlew testDebugUnitTest assembleRelease` (`JAVA_HOME`은 JDK 17).
- 서명 키: `~/harugyeol-keys/keystore.properties`(또는 `-Pharugyeol.keystoreProperties=<경로>`). 파일이 없으면 release는 서명 없이 빌드된다.
- 설치: `adb install -r app/build/outputs/apk/release/app-release.apk`.
- 기기 연결이 끊기면 `adb kill-server` 후 `adb start-server`로 재시작한다.
