## 지난 습관 기록 탐색·백업 흐름 확인 (2026-10-13)

## 최신 현황·추가 보완 목록 (2026-10-12)

- 기능 구현과 README 갱신을 main에 병합·push했다. README는 앱 소개·주요 기능·설치 안내 중심이며 하루결 이름의 의미도 추가했다. 공개 APK 릴리스는 아직 생성하지 않았다.
- 아래 과거 절의 브랜치·테스트 수·미구현 표는 당시 기록이다. 현재 기준은 main, 단위 테스트 76개 통과 및 서명 릴리스 설치 확인이다.

### 코드·화면 보완

1. **주간 요약의 부분 진행 원호**: HabitsScreen의 someDone은 PARTIAL을 포함하지만 원호 비율은 완료 습관 수만 계산한다. 부분 기록만 있는 날에는 원호 길이가 0이 된다. 부분 진행이 보이도록 표시 기준을 정하고 수정할 필요가 있다. 아직 수정하지 않았다.
2. **복구 원본 파일 보관 정책**: snapshot-original-UUID.json과 손상 데이터 원본을 보존하지만 정리 정책이 없다. 반복 복원 시 파일이 늘어날 수 있으므로 사용자가 확인·내보내기·정리할 방법을 검토한다. 데이터 보존을 우선하며 자동 삭제는 별도 정책 결정 후 적용한다.

### 출시 전 우선 검증

1. **백업·복구 전체 흐름**: 최종 APK에서 파일 선택 → 교체 복원 → 스냅샷 되돌리기, 손상 파일 거부, 실행/일시정지 타이머 정리, 복원 버튼 연속 입력을 확인한다. 단위 테스트와 백업 저장 성공만으로 전체 실기기 통과 처리하지 않는다.
2. **실제 업데이트**: 공개 릴리스 APK로 다운로드 → 서명·버전 검사 → 설치 → 기록 유지까지 확인한다. 설치 권한 거절·취소·실패 및 다운로드 폴더 대체 경로도 포함한다.
3. **알림·잠금화면**: 재부팅 후 알람·미루기·타이머 복구, 절전 지연, 내용 숨김, 미루기 인증 요구를 확인한다. 인증 후 완료와 잠금 상태 재발송은 이미 확인했다.
4. **접근성·지원 환경**: Android 13, TalkBack, 글씨 200%, 어두운 화면의 대비·잘림·탭 영역을 확인한다. 테마 전환 성공과 전체 접근성 검증은 구분한다.
5. **위젯·날짜 경계**: 여러 위젯·크기 변경·자정·시간대 변경과 Samsung 잠금화면 호스트 지원을 확인한다.
6. **배포 운영**: main의 GitHub Actions 결과 확인, 릴리스 APK·체크섬 게시, 서명 키 별도 백업. 현재 APK는 로컬 dist에 있으며 소스 push만으로 설치 파일이 공개되지는 않는다.

M2 위젯 확장과 M3 작업 수동 순서는 후속 기능이다. 우선순위는 부분 진행 표시 수정 → 백업/복구 검증 → 업데이트 검증 → 환경별 검증이다.

## 반복 일정·작업 알림·위젯 추가 (2026-10-12)

현재 작업 브랜치는 `codex/continue-m1`이다. 이후 절의 36/47개 테스트와 미착수 표는 이전 구현 이력이다.

- 작업 시각·종일 시각 설정, 일·주·월·년 반복, 간격·선택 요일·종료일, 회차 완료 이력과 직후 되돌리기를 추가했다.
- 월말·윤년 원래 날짜 복귀, 늦은 완료의 다음 회차 이동, 중복·오래된 회차 액션 무시, 다른 변경 후 되돌리기 거부를 검증했다. 반복 해제 후에도 과거 완료 이력을 유지한다.
- 캘린더는 조회 월의 미래 회차를 계산하고 완료 이력을 표시한다. 미래 회차·과거 완료 회차의 체크 버튼은 비활성화한다.
- 작업별 최대 5개 알림(정시·10/30/60분 전·1일 전), 현재 회차만 예약, 완료·삭제·수정 후 취소, 10분 미루기 보존과 재부팅·시간대 재예약을 구현했다.

- 저장 파일 구조는 `schemaVersion` 1이다. 출시 전에는 필드를 바꾸면 이전 파일을 읽지 못할 수 있다(출시 후에는 변환 함수로 처리).

## 7. 개발 환경 요약

- 필요 도구: JDK 17, Android SDK(platform 37.0, build-tools 37.0.0), `adb`, Git.
- 빌드·테스트: `./gradlew testDebugUnitTest assembleRelease` (`JAVA_HOME`은 JDK 17).
- 서명 키: `~/harugyeol-keys/keystore.properties`(또는 `-Pharugyeol.keystoreProperties=<경로>`). 파일이 없으면 release는 서명 없이 빌드된다.
- 설치: `adb install -r app/build/outputs/apk/release/app-release.apk`.
- 기기 연결이 끊기면 `adb kill-server` 후 `adb start-server`로 재시작한다.
