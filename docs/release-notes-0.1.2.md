# 하루결 0.1.2

알림·기록 보존 문제 5개를 수정하고 습관 상세에서 바로 삭제할 수 있도록 추가한 업데이트입니다.

- 습관을 누른 뒤 '습관 삭제'로 필요 없는 습관과 기록을 삭제할 수 있습니다. 확인창에서 취소할 수 있으며, 해당 습관에 타이머가 남아 있으면 먼저 정리해야 합니다.
- 다른 기록을 바꿔도 아직 발송되지 않은 같은 작업 알림의 예약을 유지합니다.
- 하루 요약 알림 채널이 차단되어 있으면 같은 시각의 습관 알림을 따로 예약합니다.
- 저장·백업 쓰기에도 20MiB 한도를 적용해 앱이 다시 읽을 수 없는 파일 생성을 막습니다. 초과 시 기존 기록을 유지하고 안내합니다.
- 날짜·시각·시간대 변경 시 화면 날짜를 갱신하고 기록 직전의 현재 날짜를 확인합니다.
- 타이머 화면을 떠나거나 앱이 백그라운드로 이동할 때 마지막 측정량을 보존합니다.

Android 13 이상, 패키지 com.bossxor.harugyeol, versionCode 4. 기존 앱을 삭제하지 않고 Harugyeol-0.1.2.apk를 덮어 설치하세요. 설치 전 파일 백업을 권장합니다. 기존 서명 키와 데이터 형식을 유지합니다.

## 화면 개선

네이비 계열 다크모드, 밝은 화면의 부드러운 카드, 오늘 진행 요약, 하단 메뉴 아이콘과 타이머 화면을 개선했습니다. 글씨가 큰 경우의 기록 버튼 배치를 유지합니다.

## 검증

최종 단위 테스트 97개, 기존 키로 서명한 R8 릴리스 빌드·lint 통과(오류 0·경고 21). Android 13 CI 에뮬레이터와 Android 17 별도 패키지 핵심 회귀 검증을 통과했습니다. S26 Ultra에 최종 APK를 설치하고 습관 생성·삭제 취소·삭제, 밝은/어두운 화면·상태바, 주요 빈 화면 200% 글씨를 확인했습니다.

연결 기기의 기존 데이터·테스트 항목은 사용자 요청으로 초기화했으며 배포 APK에 자동 초기화 코드는 없습니다. 새로 설치하면 빈 상태로 시작하고 기존 앱의 덮어 설치는 데이터를 유지합니다.

실제 Doze 지연·수정 APK의 물리적 재부팅·전체 폼·TalkBack 음성 탐색·설치 실패 경로는 추가 검증 대상입니다. 상세 결과는 docs/progress.md에 기록했습니다.

APK의 SHA256은 SHA256SUMS-0.1.2.txt에서 확인할 수 있습니다.
