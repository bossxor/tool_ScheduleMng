# 하루결 0.1.2

알림 누락과 기록 보존 문제 5개를 수정한 업데이트입니다.

- 다른 기록을 바꿔도 아직 발송되지 않은 같은 작업 알림의 예약을 유지합니다.
- 하루 요약 알림 채널이 차단되어 있으면 같은 시각의 습관 알림을 따로 예약합니다.
- 저장·백업 쓰기에도 20MiB 한도를 적용해 앱이 다시 읽을 수 없는 파일 생성을 막습니다. 초과 시 기존 기록을 유지하고 안내합니다.
- 날짜·시각·시간대 변경 시 화면 날짜를 갱신하고 기록 직전의 현재 날짜를 확인합니다.
- 타이머 화면을 떠나거나 앱이 백그라운드로 이동할 때 마지막 측정량을 보존합니다.

Android 13 이상, 패키지 com.bossxor.harugyeol, versionCode 4. 기존 앱을 삭제하지 않고 Harugyeol-0.1.2.apk를 덮어 설치하세요. 설치 전 파일 백업을 권장합니다. 기존 서명 키와 데이터 형식을 유지합니다.

수정 커밋의 단위 테스트 95개와 Android 13 에뮬레이터·Android 17 별도 패키지 런타임 회귀 검증을 통과했습니다. 원래 개발 PC의 최종 서명 빌드·ADB 설치 결과는 docs/progress.md에 기록합니다. 실제 Doze 지연·전체 UI·물리적 재부팅 검증과 입력/이벤트 주입 회귀 검증은 구분합니다.
