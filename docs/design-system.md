# 하루결 디자인 시스템 v0.5

상태: 구현 전 기준. 방향은 ‘스티커 컬렉션’(원색 면, 굵은 윤곽선, 납작한 벡터 그림). 값은 dp·sp 단위이며 시안에서 조정할 수 있다.
화면별 구성은 [화면 명세](screen-specs.md), 동작 규칙은 [제품 설계](product-design.md)를 따른다.

## 1. 원칙

1. 한눈에 상태가 보인다: 달성·부분·미기록·건너뜀·쉬는 날을 색, 모양, 문구 세 가지로 모두 구별한다.
2. 화려함은 면과 그림에서 오고 글자는 차분하다: 색 면은 크게, 글자는 대비 높게 쓴다.
3. 평평하다: 그림자 번짐·그라데이션·질감을 쓰지 않는다. 깊이는 윤곽선과 단색 오프셋 그림자로만 낸다.
4. 같은 것은 같게 보인다: 습관 색 하나가 카드·스티커·달력·알림 아이콘 전부에 일관되게 쓰인다.

## 2. 색상

### 2.1 습관 색 (4색)

습관마다 `colorIndex`(0 빨강, 1 파랑, 2 노랑, 3 초록) 하나를 고른다.

| 역할 | 빨강 | 파랑 | 노랑 | 초록 | 쓰는 곳 |
|---|---|---|---|---|---|
| fill | `#E24B4A` | `#378ADD` | `#EF9F27` | `#639922` | 스티커 원, 진행 막대, 큰 버튼 면 |
| on-fill | `#FFFFFF` | `#FFFFFF` | `#412402` | `#FFFFFF` | fill 위의 글자·아이콘 (아래 규칙 참고) |
| deep | `#A32D2D` | `#185FA5` | `#854F0B` | `#3B6D11` | 밝은 바탕 위의 색 글자·작은 아이콘 |
| tint | `#FCEBEB` | `#E6F1FB` | `#FAEEDA` | `#EAF3DE` | 카드·칩의 연한 배경 |
| dark-text | `#F09595` | `#85B7EB` | `#FAC775` | `#97C459` | 어두운 모드의 색 글자·작은 아이콘 |
| dark-tint | `#791F1F` | `#0C447C` | `#633806` | `#27500A` | 어두운 모드의 카드·칩 배경 |

- 흰색 글자와 fill의 대비는 3.4~3.9:1이다. 큰 글자 기준(3:1)만 만족하므로 **fill 위 흰 글자는 주아 16sp 이상이나 Pretendard 굵은 18sp 이상에만** 쓴다. 작은 글자는 흰색·tint 바탕 위에 deep 색으로 쓴다.
- 노랑 fill은 흰 바탕과 대비가 2.1:1이라 노랑 단독 선·글자·아이콘을 쓰지 않는다. 항상 진한 윤곽선과 함께 쓴다.
- 어두운 모드에서도 fill 값은 그대로 쓴다(어두운 배경 대비 4:1 이상). 글자와 작은 아이콘만 dark-text로 바꾼다.

### 2.2 중립색과 상태색

| 토큰 | 밝은 모드 | 어두운 모드 | 용도 |
|---|---|---|---|
| bg | `#FFFDF7` | `#1B1B1F` | 화면 바탕 |
| surface | `#FFFFFF` | `#26262C` | 카드·시트·입력 칸 |
| outline | `#2C2C2A` | `#F4F1EA` | 윤곽선, 오프셋 그림자, 기본 글자 |
| text | `#2C2C2A` | `#F4F1EA` | 기본 글자 |
| text-sub | `#5F5E5A` | `#B4B2A9` | 보조 글자 |
| dashed | `#888780` | `#888780` | 점선 윤곽(미기록 자리), 비활성 아이콘 |
| stripe-bg | `#F1EFE8` | `#2C2C2A` | 건너뜀 줄무늬 바탕 |
| stripe | `#D3D1C7` | `#444441` | 건너뜀 줄무늬 선 |
| achieved-bg | `#EAF3DE` | `#173404` | 달성 카드 바탕 |
| achieved-text | `#27500A` | `#C0DD97` | 달성 글자 |
| error-bg | `#FCEBEB` | `#501313` | 오류 배너 바탕 |
| error-text | `#A32D2D` | `#F09595` | 오류 글자·삭제 버튼 |

- 달성 상태는 습관 색과 관계없이 초록 계열이다. 초록 습관은 색이 겹치므로 체크 아이콘·‘달성’ 문구·스티커 효과로 구별한다.
- `dashed`(`#888780`)는 밝은 바탕 대비 3.5:1이라 글자에는 쓰지 않는다. 비활성 글자도 text-sub를 쓴다.

### 2.3 대비 확인값 (WCAG, 계산값)

| 조합 | 대비 | 기준 |
|---|---|---|
| text `#2C2C2A` / bg `#FFFDF7` | 13.8 | 통과 |
| on-fill `#412402` / 노랑 `#EF9F27` | 6.5 | 통과 |
| deep `#185FA5` 등 / 흰색 | 6.2~7.1 | 통과 |
| text-sub `#5F5E5A` / bg `#FFFDF7` | 6.4 | 통과 |
| 흰색 / 빨강·파랑·초록 fill | 3.4~3.9 | 큰 글자만 |
| text `#F4F1EA` / bg `#1B1B1F` | 15.2 | 통과 |
| dark-text 4색 / surface `#26262C` | 6.8~9.7 | 통과 |

구현 후 실제 렌더링 색으로 다시 측정한다.

## 3. 글자

| 이름 | 글자체 | 크기/줄 높이 | 굵기 | 용도 |
|---|---|---|---|---|
| display | 주아 | 32/40 | 기본 | 오늘 요약 숫자, 전부 달성 문구 |
| title | 주아 | 24/32 | 기본 | 화면 제목 |
| headline | 주아 | 18/26 | 기본 | 습관 이름, 섹션 제목, 시트 제목 |
| button | 주아 | 16/24 | 기본 | 버튼 문구 |
| body | Pretendard | 16/24 | Regular | 본문, 메모, 입력 |
| body-s | Pretendard | 14/20 | Regular | 설명, 보조 |
| number | Pretendard | 16/24 | SemiBold | 진행량·시간·날짜 숫자 |
| caption | Pretendard | 12/16 | Regular | 달력 요일, 보조 표시(최소 크기) |

- 주아는 16sp 미만에 쓰지 않고 입력 칸에는 쓰지 않는다. 사용자가 입력한 습관 이름은 주아로 표시하되 길면 2줄까지 줄바꿈 후 말줄임한다.
- 글자 크기 설정은 sp로 따른다. 200% 확대에서도 버튼·카드가 잘리지 않고 줄바꿈되어야 한다. 카드 높이는 내용에 맞춰 늘어난다.
- 숫자는 균등 너비(tabular) 숫자를 써서 값이 변할 때 흔들리지 않게 한다.

| 항목 | 값 |
|---|---|
| 간격 단위 | 4dp (4·8·12·16·24·32) |
| 화면 좌우 여백 | 16dp |

| 오프셋 그림자 | 오른쪽·아래 3dp 단색, 번짐 없음. 밝은 모드는 outline 색, 어두운 모드는 습관 dark-tint 색 |
| 눌림 | 카드·버튼을 오른쪽·아래로 3dp 이동하고 오프셋 그림자를 없앤다 |

| 스티커 지름 | 32(주간 띠·달력) · 56(카드) · 72(상세) · 96(마일스톤) |

## 5. 컴포넌트

### 5.1 스티커 (원형 그림)

- 구성: 바깥 원(습관 fill, 3dp 윤곽선) 안에 흰 원판(지름의 74%, 밝은·어두운 모드 모두 `#FFFFFF`)을 놓고 그 안에 그림(지름의 56%)을 넣는다. 그림이 여러 색이어도 흰 원판 위라 읽힌다.
- 달성: 바깥 원 fill 채움 + 오른쪽 아래 초록 체크 배지(지름의 30%) + 그림 선명.
- 부분 기록: 바깥 원은 tint, 둘레에 습관 fill 진행 링(12시 방향에서 시계 방향)이 목표 비율만큼 채워진다. 그림 선명.
- 미기록: 바깥 원 없이 점선 원(dashed 2dp) + 흰 원판 + 그림 알파 40%.
- 건너뜀: stripe 줄무늬 바깥 원 + 윤곽선 + 그림 알파 50%.
- 쉬는 날: text-sub 1dp 윤곽 + 흰 원판 + 그림 알파 35%.
- 상태는 색 외에 모양(채움·링·점선·줄무늬)과 체크 배지로도 구별된다.

### 5.2 습관 카드

- 높이는 내용에 따라 최소 88dp. 왼쪽 스티커(56), 가운데 이름(headline)·진행 막대·진행량(number), 오른쪽 기록 버튼(48) 순이다. 우측 끝에 더보기(⋮, 48)는 길게 눌러 열리는 메뉴로도 접근한다.
- 진행 막대: 높이 10dp, 윤곽선 2dp, 채움은 습관 fill, 목표 이상이면 100%에서 멈추고 초과량은 숫자로만 표시(`12/8잔`).
- 상태별 카드 바탕: 미기록·부분 = surface, 달성 = achieved-bg + 오른쪽 위 ‘달성’ 칩, 건너뜀 = stripe-bg, 쉬는 날 = surface + 흐린 윤곽.
- 기록 버튼: 완료형 = 체크 원 버튼(토글), 수량형 = `＋1` 알약(길게 누르면 직접 입력 시트), 시간형 = 재생 알약(타이머 화면), 타이머 실행 중에는 경과시간 알약 `12:34`(탭 시 타이머).

### 5.3 버튼

| 종류 | 모양 | 용도 |
|---|---|---|
| primary | fill 습관색 또는 파랑 `#378ADD` 면 + 윤곽선 + 오프셋 그림자, 주아 16 | 화면당 하나의 주 동작(저장·추가) |
| secondary | surface 면 + 윤곽선 | 보조 동작(취소·나중에) |
| danger | error-bg 면 + error-text 글자 + 윤곽선 | 삭제·교체 복원 |
| text | 윤곽 없음, deep 색 글자 | 시트 안 보조 링크 |
| icon | 48dp 원, 윤곽선 | 상단 바 동작 |
| FAB(추가) | 빨강 `#E24B4A` 56dp 원 + 윤곽선 + 오프셋 그림자, 흰 ＋ | 습관·할 일 추가 |

버튼 문구는 동사로 끝나는 2~8자(`저장`, `습관 추가`)로 쓴다.

### 5.4 입력

- 텍스트 칸: surface 면 + 2dp 윤곽선 + 12dp 모서리, 높이 56dp, Pretendard 16. 포커스는 윤곽선을 파랑 `#378ADD`로 바꾸고 3dp로 굵게 한다. 오류는 error-text 윤곽선 + 아래에 오류 문구(body-s).
- 숫자 입력: 숫자 키패드, 단위 표시(`잔`, `분`)를 칸 안 오른쪽에 둔다.
- 스위치·체크: 켜짐은 파랑 fill + 윤곽선, 꺼짐은 surface + 윤곽선. 터치 영역 48dp.
- 요일 선택: 7개 원형 칩(월~일), 선택은 습관 fill 면 + 흰/갈색 글자.
- 시각 선택: 시스템 시간 선택기를 쓴다(Material 시간 선택).

### 5.5 상단 바·하단 메뉴·시트

- 상단 바: 높이 56dp, 제목(title), 오른쪽 아이콘 최대 2개. 스크롤 시 아래 1dp 구분선만 나타난다.
- 하단 메뉴: 높이 64dp + 안전 영역, 윗선 2dp outline. 항목 4개(습관·할 일·캘린더·설정). 라벨은 Pretendard SemiBold 12(주아는 16sp 이상에만 쓴다). 선택된 항목은 아이콘 뒤 원이 원색 fill로 채워진다. 선택 색은 항목별 고정: 습관 빨강, 할 일 파랑, 캘린더 노랑, 설정 초록.
- 하단 시트: 상단 모서리 24dp, 윗선 2dp outline, 손잡이 막대. 입력·메뉴·확인에 쓴다.
- 확인 대화상자: 중앙, 모서리 16dp, 2dp outline, 버튼 두 개(취소 secondary / 확정 primary 또는 danger).
- 토스트(스낵바): 하단 메뉴 위, surface + 2dp outline, 3초, 실행 취소 버튼 포함 가능.

### 5.6 달력 칸

- 월 달력은 7열 정사각 칸(최소 44dp). 날짜 숫자(number 14)가 위, 아래에 스티커(32)가 들어간다.
- 습관 달력: 달성 = 스티커, 부분 = 진행 링 원, 건너뜀 = 줄무늬 원, 비대상 날 = 칸 비움(숫자만 text-sub), 시작일 이전 = 숫자 희미(text-sub), 미래 = 숫자만.
- 오늘은 칸에 3dp outline, 선택한 날짜는 파랑 윤곽선 + tint 바탕.
- 할 일 캘린더: 날짜 아래에 점 최대 3개(우선순위색은 쓰지 않고 파랑 단색), 4개 이상이면 `+`.

### 5.7 칩·배지

- 우선순위: 없음(표시 없음), 낮음 = 파랑 ▽ 1줄, 중간 = 노랑 ▽▽ 2줄, 높음 = 빨강 ▲ 3줄. 모양(줄 수)과 문구로 구별하며 색만으로 표현하지 않는다.
- 태그 칩: tint 바탕 + 2dp outline 없이 1dp 윤곽, 글자 body-s.
- 상태 칩(‘달성’, ‘오늘’, ‘지남’): 알약, 높이 24dp, 글자 Pretendard SemiBold 12.

## 6. 움직임

| 동작 | 시간 | 곡선 | 설명 |
|---|---|---|---|
| 스티커 찍힘 | 320ms | overshoot | 크기 1.5→1.0, 윤곽선이 한 번 굵어졌다 돌아옴, 햅틱 확인 진동 1회 |
| 진행 막대 | 250ms | ease-out | 값 변경 시 채움이 이동 |
| 카드 상태 전환 | 150ms | linear | 바탕색 크로스페이드 |
| 화면 이동 | 200ms | standard | 좌우 슬라이드 + 페이드 |
| 시트 열림 | 220ms | ease-out | 아래에서 올라옴 |
| 전부 달성 | 600ms | ease-out | 상태 그림이 목록 위에서 한 번 내려옴 |

- 달성 효과는 ‘달성 전환이 일어난 순간’에만 실행한다. 앱 재실행·재조회·화면 회전·과거 기록 수정에서는 정적 표시다.
- 전부 달성 효과는 하루에 한 번만 보이고, 같은 날 다시 달성 상태가 되어도 반복하지 않는다. 이를 위해 마지막으로 효과를 보인 날짜를 설정에 저장한다(`lastCelebrationDate`).
- 시스템의 ‘애니메이션 제거’ 설정이면 모든 움직임을 즉시 전환으로 바꾼다. 햅틱은 시스템 설정을 따른다.

- 마음·관계: `meditate`, `journal`, `gratitude`, `family`, `smile`
- 공통: `check`, `star`, `flag`

기본 그림(그림을 고르지 않았을 때)은 이름 첫 글자를 원 안에 넣은 문자 스티커이며 주아 24를 쓴다.

### 7.3 스타일 규격

- 형식: SVG 원본 → Android Vector Drawable. 그라데이션·필터·마스크·텍스트를 쓰지 않는다(Vector Drawable로 변환이 되지 않거나 번질 수 있다).
- 화판 96×96, 안전 여백 8, 단색 면 중심. 윤곽선이 있으면 4(`#2C2C2A`)로 통일한다.
- 색: 자체 제작·AI 생성 그림은 4색 fill, 흰색, 윤곽 `#2C2C2A`, 연한 tint만 쓴다. 무료 세트는 원본 색을 그대로 써도 되지만 납작한 단색 면 스타일이어야 한다.
- 그림은 습관 색과 무관하게 한 가지 형태이며 흰 원판 위에 놓인다. 습관 색은 스티커 바깥 원이 입는다.
- 32dp에서 형태를 알아볼 수 있어야 한다. 그림 안에 글자를 넣지 않는다.
- 실존 브랜드·로고·캐릭터를 닮지 않아야 한다.

### 7.4 준비 순서와 규칙

1. **무료 일러스트 우선.** 후보 세트(라이선스는 채택할 때 저장소의 LICENSE 파일로 다시 확인한다):
   - Fluent Emoji — Flat 스타일 (MIT)
   - Noto Emoji (OFL-1.1 / 이미지는 Apache-2.0 표기 확인)
   - Tabler Icons, Phosphor Icons (둘 다 MIT, 선형 아이콘 — 상태 그림·내비게이션용)
2. 허용 라이선스: CC0, MIT, Apache-2.0, OFL. 제한: CC BY-SA(동일 조건 변경 허락), CC BY-NC(비상업), 라이선스 불명은 쓰지 않는다. 표기가 필요한 라이선스는 앱 내 ‘오픈소스 라이선스’ 화면에 싣는다.
3. 한 세트에서 필요한 그림을 못 찾으면 **AI로 생성해 선별**한다. 요청 문구 틀:
   `flat vector sticker icon of <대상>, solid fills only, uniform thick dark outline #2C2C2A, palette #E24B4A #378ADD #EF9F27 #639922 #FFFFFF, no gradient, no shadow, no texture, no text, centered on transparent background`
   생성 결과는 벡터로 변환하고 팔레트에 맞춰 색을 정리한다. 도구·날짜·요청 문구를 기록하며 상업적 사용 약관을 확인한 도구만 쓴다.
4. 모든 그림은 `assets/icons/<키>.svg`에 두고 `assets/LICENSES.md`에 키, 출처, 라이선스, 변경 여부(색 정리 등), 작성일을 한 줄씩 적는다. 기록 없는 그림은 병합하지 않는다.
5. 채택 점검표: 스타일 규격 충족, 32·56dp에서 판독, 밝은·어두운 모드 모두에서 윤곽이 보임, 출처 기록 완료.

## 8. 앱 아이콘

- 모양: 파랑 `#378ADD` 하늘 바탕 + 노랑 `#EF9F27` 해(원) + 해 안쪽의 굵은 체크(흰색) + 짧은 광선 8개. 모든 선은 `#2C2C2A` 윤곽선.
- 어댑티브 아이콘: 108dp 화판, 안전 영역 66dp 안에 해와 광선, 바탕 레이어는 단색 파랑, 전경 레이어는 해+체크.
- 테마 아이콘(Android 13+): 해와 체크를 단색 실루엣으로 제공한다.
- 런처 이름은 ‘하루결’, 영문 표기 ‘Harugyeol’은 릴리스 파일명·앱 정보 화면에 쓴다.

## 9. 접근성

- 대비: 2.3의 값을 지킨다. 새 색을 추가하면 같은 방식으로 계산해 기록한다.
- 터치 영역 48×48dp, 간격 8dp 이상. 아이콘만 있는 버튼은 접근성 레이블을 둔다(`＋1`은 ‘물 마시기, 한 잔 추가’처럼 대상을 포함).
- TalkBack: 카드는 ‘물 마시기, 8잔 중 3잔, 한 잔 추가 버튼’처럼 하나의 항목으로 읽고, 달성은 ‘달성’으로 읽는다. 스티커 그림은 장식이라 읽지 않는다.
- 색맹: 모든 상태가 색 외에 모양·문구를 갖는다(5.1, 5.7).
- 글자 크기: 시스템 글자 크기 200%, 화면 크기 400% 근처에서 가로 스크롤이 생기지 않는다.
- 햅틱·모션: 시스템 설정을 따르며 끌 수 있다(설정 > 달성 효과 진동).
- 시간 제한이 있는 UI를 두지 않는다. 토스트의 ‘실행 취소’는 3초 후 사라지되 같은 동작을 메뉴에서도 할 수 있다.

## 10. 문구 규칙

- 존댓말(해요체)로 짧게 쓴다: ‘저장했어요’, ‘기록이 없어요’. 느낌표와 이모지를 쓰지 않는다.
- 비난하지 않는다: 미달성은 ‘아직 기록이 없어요’, 연속 달성이 끊겨도 ‘다시 시작해요’ 정도로만 안내한다.
- 오류는 무슨 일이 일어났는지와 다음 행동을 한 문장씩 쓴다: ‘파일을 읽을 수 없어요. 다른 백업 파일을 선택해 주세요.’
- 숫자와 단위는 붙여 쓰고 천 단위 구분은 기기 설정을 따른다.
- 주요 문구 목록은 [화면 명세](screen-specs.md)의 각 화면에 둔다.
