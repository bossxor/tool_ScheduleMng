# 하루결 남은 작업

기준일: 2026-10-13. main 병합·push 완료.

## 추가 검증에서 재현된 결함

제품 코드 `793991b`에서 다음 세 항목을 재현했다. [검증 보고](verification-20261013.md)와 별도 진단 소스를 함께 보관한다.

- 변경 없는 작업의 지연 알림이 전체 재예약에서 취소된다. 시각 주입과 실기기 OS 예약 개수 1→0으로 확인했다.
- Android 요약 채널만 차단하면 같은 시각의 습관 예약도 제외되어 알림이 누락된다. 별도 검증 앱에서 채널·게시 상태를 확인했다.
- 20MiB 초과 데이터를 쓰기는 허용하지만 다시 읽기는 거부한다. 유효한 21,777,420바이트 파일로 확인했다. 원본은 보존됐다.

기존 87개 단위 테스트는 통과했다. 추가 진단 테스트의 통과는 결함 재현 성공이며 수정 완료를 뜻하지 않는다.
후속 브랜치에서 위 세 항목과 자정 날짜·타이머 화면 이탈 보존을 수정했다. 단위 테스트 95개·R8 빌드·lint 통과, 수정 후 런타임 검증은 진행 중이다. [수정 보고](five-fixes-20261013.md).

## M1 구현

습관 시작일·메모·45개 그림·추천 6개·읽기 전용 보관함, 목록·태그·체크리스트·반복 작업, 테마·진동·달성 효과·스티커 모음, 타이머 화면 유지·전환, 알림 기록 액션·지난 시각 안내, 손상 데이터 복구, 앱 내 라이선스와 R8 축소까지 구현했다. 저장 성공을 기다리고 복원 중복 실행을 막는다. 기존 schema 1 및 복원 스냅샷 원문을 보존한다.

## 추가 보완

- 주간 요약 부분 진행 원호 계산 보완 완료. 검증 결과는 progress.md 참조.
- 동일 복구 원본 중복 보존 방지 구현. 서로 다른 원본은 유지한다. 확인·내보내기·정리 UI는 후속 검토.
- 파일 선택 백업·같은 데이터 교체 복원·스냅샷 되돌리기와 전후 JSON 동일 확인 완료. 손상 파일은 교체 확인창이 열리지 않음을 확인. 일시정지 타이머의 복원 전 정리 요구를 확인했고 저장 실패 원본 보존은 테스트로 검증. 실행 중 타이머 복원·OS 저장공간 부족은 실기기 미검증.

## 출시 환경 검증

- v0.1.1 공개 및 실제 앱 업데이트·권한 허용·설치 후 기록/타이머 유지·최신 표시 완료. 권한 거절·설치 취소/실패의 실기기 경로는 별도 미검증.
- Android 13 실기기, TalkBack 전체 음성 탐색, 삼성 절전·시간대 경계. 타이머 재부팅 복구와 요약 알람 재예약 완료, 미루기 재부팅은 별도. TalkBack은 개인용 앱의 권장 점검으로 출시 차단 조건이 아니다. 200% 주요 화면 점검과 습관 카드 보완은 완료했으며 전체 폼·달력·긴 제목은 추가 점검 대상.
- 삼성 잠금화면 위젯 선택 지원, 내용 숨김, 여러 위젯·크기 변경.
- 서명 키 별도 백업은 사용자 보관 작업.
