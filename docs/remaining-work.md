# 하루결 남은 작업

기준일: 2026-10-13. main 병합·push 완료.

## M1 구현

습관 시작일·메모·45개 그림·추천 6개·읽기 전용 보관함, 목록·태그·체크리스트·반복 작업, 테마·진동·달성 효과·스티커 모음, 타이머 화면 유지·전환, 알림 기록 액션·지난 시각 안내, 손상 데이터 복구, 앱 내 라이선스와 R8 축소까지 구현했다. 저장 성공을 기다리고 복원 중복 실행을 막는다. 기존 schema 1 및 복원 스냅샷 원문을 보존한다.

## 추가 보완

- 주간 요약 부분 진행 원호 계산 보완 완료. 검증 결과는 progress.md 참조.
- 동일 복구 원본 중복 보존 방지 구현. 서로 다른 원본은 유지한다. 확인·내보내기·정리 UI는 후속 검토.
- 최종 APK의 파일 선택 복원·스냅샷·손상 거부·타이머 동시 처리 흐름을 실기기 검증한다.

## 출시 환경 검증

- 실제 GitHub 공개 릴리스를 통한 자동 업데이트·권한 거절·설치 취소/실패의 종단 간 검증.
- Android 13 실기기, TalkBack, 200% 글씨, 삼성 절전·재부팅·시간대 경계.
- 삼성 잠금화면 위젯 선택 지원, 내용 숨김, 여러 위젯·크기 변경.
- 서명 키 별도 백업은 사용자 보관 작업.

## 후속 범위

M2: 위젯 목록·직접 기록·빠른 추가·타이머·구성. M3: 작업 수동 순서. 현재 M1 완료 범위에 포함하지 않는다.
