# 하루결

**하루의 습관과 할 일을 한곳에서 관리하는 개인용 Android 앱입니다.**

[프로젝트 대시보드](https://bossxor.github.io/works-dashboard/) · [최신 릴리스](https://github.com/bossxor/tool_ScheduleMng/releases/latest) · [APK 다운로드](https://github.com/bossxor/tool_ScheduleMng/releases/download/v0.1.2/Harugyeol-0.1.2.apk)

물 마시기, 독서, 운동처럼 꾸준히 하고 싶은 일은 습관으로 기록하고, 날짜가 정해진 일은 할 일로 관리할 수 있습니다. 오늘의 진행 상황부터 지난 기록까지 달력과 스티커로 확인하세요.

**하루결**은 '하루'와 '결'을 이어 붙인 이름입니다. 하루하루 쌓이는 작은 습관과 기록이 나만의 삶의 결을 만들어 간다는 뜻을 담았습니다. 매일의 성취뿐 아니라 쉬어 간 날도 함께 기록하며, 내 일상의 흐름을 살펴보는 앱을 지향합니다.

로그인 없이 사용할 수 있으며, 기록은 휴대폰 안에 저장됩니다. 인터넷 연결은 GitHub에서 앱 업데이트를 확인하고 내려받을 때 사용합니다.

## 주요 기능

### 습관을 꾸준히 기록하기

- 완료 체크, 수량, 시간 목표를 지원합니다.
- 매일, 선택한 요일, 주 몇 회 등 목표 주기를 설정할 수 있습니다.
- 타이머나 직접 입력으로 활동 시간을 기록합니다.
- 시작일부터 지난 기록을 수정하고, 쉬는 날은 건너뛸 수 있습니다.
- 기록 달력, 달성률, 연속 달성과 스티커 모음으로 진행 상황을 확인합니다.
- 주간 날짜를 누르거나 캘린더의 어제·오늘 버튼으로 지난 습관 기록을 볼 수 있습니다.
- 추천 습관, 그림 선택, 메모, 보관함으로 습관을 관리합니다.
- 습관을 누른 뒤 **습관 삭제**로 필요 없는 습관과 기록을 삭제할 수 있습니다. 기본 샘플은 자동으로 추가하지 않습니다.

### 할 일과 반복 일정 관리하기

- 날짜·시간·우선순위·메모를 지정하고 체크리스트를 붙일 수 있습니다.
- 목록과 태그로 분류하고 제목·메모를 검색합니다.
- 오늘, 예정, 받은함, 전체, 완료 보기와 월 달력을 제공합니다.
- 일·주·월·년 반복, 반복 간격·요일·종료일을 설정할 수 있습니다.
- 반복 작업의 완료 이력을 보관하고, 완료 직후 되돌리기를 지원합니다.
- 삭제한 할 일은 휴지통에서 복원하거나 완전히 삭제할 수 있습니다.

### 알림과 위젯으로 확인하기

- 습관별 알림, 하루 요약 알림과 할 일 알림을 제공합니다.
- 할 일 알림에서 완료하거나 10분 미룰 수 있습니다.
- 수량·시간 습관 알림에서 기록 화면을 열 수 있습니다.
- 홈 화면 위젯에서 오늘의 습관·할 일 요약을 확인합니다.
- 잠금화면 알림의 기록 변경은 잠금 해제 후 실행됩니다. 잠금화면 위젯 배치는 기기의 지원 여부에 따라 달라집니다.

### 내 기록 보관하기

- 파일 백업·복원과 내부 스냅샷 되돌리기를 지원합니다.
- 밝은 테마, 네이비 다크모드, 시스템 테마와 달성 진동을 선택할 수 있습니다. 오늘 진행 요약과 아이콘 메뉴로 기록을 확인합니다.
- 앱에서 GitHub의 새 릴리스를 확인하고 APK 업데이트를 설치할 수 있습니다.

백업 파일은 암호화되지 않으며 개인 기록을 포함합니다. 안전한 위치에 보관하세요.

## 설치와 사용

**Android 13 이상**을 지원합니다.

1. [최신 릴리스](https://github.com/bossxor/tool_ScheduleMng/releases/latest)에서 APK를 내려받아 설치합니다. 현재 공개 버전은 **0.1.2**입니다.
2. Android에서 요청하면 APK를 연 앱의 설치 권한을 허용합니다.
3. 습관 또는 할 일을 추가하고, 알림을 사용하려면 알림 권한을 허용합니다.
4. 설정에서 정확한 알람과 배터리 제한 상태를 확인합니다. 기기의 절전 설정에 따라 알림이 지연될 수 있습니다.

업데이트할 때는 기존 앱을 삭제하지 않고 APK를 덮어 설치하세요. 설치 전 파일 백업을 권장합니다.

## 현재 상태

첫 버전(M1)을 구현하고 **0.1.2을 공개 배포**했습니다. 97개 단위 테스트, 서명·R8 릴리스 빌드, GitHub Actions 빌드를 통과했습니다.

Galaxy S26 Ultra에서 실제 앱 업데이트·기록과 타이머 유지·재부팅 복구, 파일 백업·복원·스냅샷 되돌리기, 200% 글씨의 주요 화면을 확인했습니다.

후속 수정 브랜치에서는 알림·저장·날짜·타이머 결함 5개를 수정했습니다. 단위 테스트 95개와 Android 13 에뮬레이터·S26 Ultra / Android 17 런타임 회귀 검증을 통과했습니다. 공개 APK에는 아직 반영되지 않았습니다. [수정·검증 보고](docs/five-fixes-20261013.md).

Android 13 별도 기기·TalkBack 전체 음성 탐색·일부 설치 실패와 알림 복구 등 환경별 검증은 남아 있습니다. 프로젝트 대시보드는 [여기](https://bossxor.github.io/works-dashboard/)에서 열 수 있으며, 상세 구현·검증 결과는 [진행 기록](docs/progress.md)과 [남은 검증](docs/remaining-work.md)에 정리되어 있습니다.
