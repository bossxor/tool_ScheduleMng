# 하루결

TickTick의 기능 구성을 참고한 개인용 안드로이드 일정·할 일 관리 앱입니다.
현재 단계는 **설계 v0.5**이며, 습관·체크인·타이머, 기본 할 일·반복 일정·작업 알림·월 캘린더·오늘 요약 위젯이 구현되어 실기기에서 확인 중입니다. 진행 상황은 [docs/progress.md](docs/progress.md)를 참고하세요.

## 제품 방향

- 개인용, 오프라인 우선. 첫 버전은 로그인과 서버 없이 동작합니다. 네트워크는 앱 업데이트에만 씁니다.
- 습관·날짜별 체크인을 최우선으로 완성합니다. 목표 주기, 기록 달력, 연속 달성·달성률, 쉬는 날 건너뛰기를 첫 버전에 포함합니다.
- 습관 목표는 완료 여부·수량·시간을 지원합니다. 원색과 납작한 벡터 그림, 달성하면 모이는 스티커로 달성과 진행률을 강조하는 활기찬 화면으로 설계합니다(제목 주아, 본문 Pretendard).
- 시간은 타이머와 수동 입력을 지원합니다. 습관별 여러 시각 알림과 하루 한 번 요약 알림을 함께 제공합니다.
- 시작일부터 모든 과거 기록을 수정할 수 있습니다.
- 데이터는 DB 없이 앱 내부 JSON 파일 하나에 저장합니다. 백업은 같은 형식의 암호화 없는 파일입니다.
- 할 일, 반복 일정, 알림, 캘린더, 파일 백업, 자동 업데이트도 첫 버전에 한 번에 포함합니다.
- 기본 오늘 요약 위젯과 잠금화면 사용을 추가합니다. 위젯 확장·집중 타이머·종합 통계는 후속 단계입니다.
- TickTick의 이름·로고·화면 자산을 사용하지 않는 독립 앱으로 설계합니다.
- 배포는 이 저장소의 GitHub Releases APK입니다. 앱을 열 때마다 새 릴리스를 확인해 바로 내려받고, 앱 내부 설치가 안 되면 다운로드 폴더의 APK로 설치합니다. 우선 검증 기기는 사용자의 갤럭시 S26 울트라입니다.
