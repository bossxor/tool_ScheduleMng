# tool_ScheduleMng

TickTick의 기능 구성을 참고한 개인용 안드로이드 일정·할 일 관리 앱입니다.
현재 단계는 **설계 초안 v0.1**이며 앱 구현은 시작하지 않았습니다.

## 제품 방향

- 개인용, 오프라인 우선. 첫 버전은 로그인과 서버 없이 동작합니다.
- 할 일, 반복 일정, 알림, 캘린더, 파일 백업을 먼저 완성합니다.
- 습관, 집중 타이머, 위젯, 통계는 후속 단계입니다.
- TickTick의 이름·로고·화면 자산을 사용하지 않는 독립 앱으로 설계합니다.

그 외 기술·화면·기능 우선순위는 검토 가능한 제안입니다.

설계 기준일: 2026-10-11 (Asia/Seoul).
